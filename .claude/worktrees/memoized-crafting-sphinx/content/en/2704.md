Anton Vedeshin hosted a project named [PHPMapReduce on SourceForge](http://www.sourceforge.net/phpmapreduce), but without any update yet. The name is so attractive that many people, like me, want it. MapReduce is such a good architect that can solve many interesting problems, but Hadoop is, like many Java application, too big. We need something like that in PHP world.

If PHPMapReduce still does not come, I may want to write a MapReduce framework myself and share it with the open source community.
