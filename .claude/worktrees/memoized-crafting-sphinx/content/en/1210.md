The learning is, do NOT easily start a new project (development or installation) before you think carefully about it and plan for it. Otherwise, the project starts quickly and dies quickly. For example, the few successful application listed here, I would say, are [map], [wap] and [mtcn].

The only common element among these three are: they need daily access and is among the best of its kind. Map is the application to allow people to mark points onto it and distribute it to friends. Mtcn is the MovableType installation for my friends (fanfan, mvm, claire, elfe, and cn). wap is the application that allows me to check new comments posted onto the web everyday.

Now I want to install another application called Lilina. Today is Christmas and I want to install the tool to help me keep in touch with my friends better. When I created the entry of yesterday, I found most of my friends have blog now. I will use Lilina to keep track of what they are doing.
