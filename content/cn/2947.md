去年，我花了非常多的时间研究 Web3 ， 写了[很多文章](http://mp.weixin.qq.com/s?__biz=MjM5NzI0Mjg0MA==&mid=2652375278&idx=1&sn=f6590fa98241b520f4d6ce5d468fa7e1&chksm=bd305a598a47d34f0aa8dbe24b096242d9adfc5435526e8257d5be16c4c53b81c3a8e1c0b434&scene=21#wechat_redirect)，也去参加了 Web3 领域一些重要的大会。

我一直想找到一个切入口，可以加入这场大潮，但总是像大狗想吃刺猬，转了十几个圈，找不到一个可以下嘴的地方。「我能干什么？我能提供什么价值？什么地方需要我？」这些问题，我一直找不到一个清晰的答案。

直到 ChatGPT 的出现，让我想明白了一件事情：我对于 Web3 相当于互联网的哪一年这个问题的判断，还是过于乐观了。我曾经以为[今天的 Web3 相当于互联网的 1993 年](http://mp.weixin.qq.com/s?__biz=MjM5NzI0Mjg0MA==&mid=2652374634&idx=1&sn=da0d6db501fc4c58744a1b9d6aac36e1&chksm=bd3054dd8a47ddcb6f56e26e505a33816245d3edae375577097cf2a6f023c160e68d6cd33bbe&scene=21#wechat_redirect)，也就是浏览器诞生的前一年。但现在看起来，如果说 [ChatGPT 出现相当于浏览器的诞生](http://mp.weixin.qq.com/s?__biz=MjM5NzI0Mjg0MA==&mid=2652376288&idx=1&sn=dadc90b567ba31c21c348bd46b30fa58&chksm=bd305e578a47d741ee99c16894e400d60c9cc2dbe1116830e7548b2f8310c1920cd9b9c33777&scene=21#wechat_redirect)，那么现在 Web3 在区块链的时间线上，估计只走到了 1979 年，还有很多年才可以走到 1994 年。‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍

我依然坚定的相信区块链改变人类的巨大能力，这是源于底层判断：互联网   给了一比特信息瞬间传输到全球的任何一个角落的能力，区块链给了一比特信息不可更改的能力（见《[为什么我现在就敢断言，区块链技术是和互联网技术至少一样重要的技术？](http://mp.weixin.qq.com/s?__biz=MjM5NzI0Mjg0MA==&mid=2652375808&idx=1&sn=07195b4637520f50faf97d57dd957917&chksm=bd3059b78a47d0a1a8f9fa193d441657febe69c421b33d6098124ee8f83be202316579e4d32c&scene=21#wechat_redirect)》。但基础的能力，变成全民的工具，需要沿着一个脉络一步步的发展。Web3 领域可以引发如同浏览器，Google，iPhone 一样全民参与的产品到底什么时候才能出现呢？整个行业依然在等待。

**在 Web3 行业等待，是不是一定会有机会呢？**

这可能是一个危险的选择。

浏览器开启了 Web 时代（World Wide Web）。 WWW 是由一系列协议栈组成的：包括用浏览器显示内容，用 HTML 表示内容， 用 URL 定位内容， 用 HTTP 传输内容。这个协议栈，在浏览器诞生前的互联网，是众多协议栈中的一种而已，只不过它因为易用性和扩展性，使得互联网上 99% 的应用都变成了 Web 应用（见[90%的应用都会消失，如今的 Web3 就像 1993 年的互联网](http://mp.weixin.qq.com/s?__biz=MjM5NzI0Mjg0MA==&mid=2652374998&idx=2&sn=9c7d66ffd8d10c7eef1430f47603da9e&chksm=bd3055618a47dc77227989b400ed98d0eb61297d4d2009c7d5a4979e08be92729e5b36f45ad7&scene=21#wechat_redirect)）。

浏览器出现了以后，与 Web 并列且有竞争关系的技术栈，几乎都被**灭族**了。这里面的公司、项目，不但自己没有了，连自己的竞争对手，模仿自己的后来者，都一起被抹去了。我印象中可能最后剩下的非 Web 应用 BitTorrent 也已经倒下了。

**ChatGPT 冲击下的 AI 公司**

我们再看 ChatGPT 出现后，受到最大冲击的，不是完全没有 AI 技术的公司，而是各种已经存在的对话机器人/客服机器人公司。这些公司在自然语言处理的大领域耕耘，却在 LLM （大语言模型） V.S. 各种特定任务小模型组合这条路上，走在了和 ChatGPT 不同的道路上。

同门兄弟相残反而是最凶残的。我去问以前在这些公司耕耘的很多年的朋友看法，他们都说「不想回答」。我可以理解这种心情：终其一生，刻苦练武的武僧看到洋枪的那一刻，估计反应也是「不想说话」。‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍

过去的所有积累一夜变成了累赘，可能需要痛下决心，裁减技术团队，转型使用 ChatGPT 为代表的大语言模型的技术路线，伤筋动骨之后，才能终于站在了大多数公司的同一个起跑线上。

Web3 领域会不会也是这样？那个互联网的浏览器一样的产品到底什么时候出来？在那个真正让最终用户奔走相告，纷纷尝试，一拍大腿说：「就是这个」的产品出来之前，所有的积累，到底是积累还是包袱吗？会被如非 Web 协议一样被灭族呢？会不会如传统聊天机器人一样被瞬间反超呢？‍‍‍‍‍‍‍‍

这至少是一个不得不思考的风险。
