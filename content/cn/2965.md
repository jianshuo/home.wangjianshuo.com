昨天回到久违的微软和跨时空的微软同事们聊 ChatGPT 的话题，有人问：如果你是微软这一块的负责人，你会怎么排兵布阵？

我说「我会听萨提亚说的每一句话。」

我这么说是发自内心的。

我在微软，经历过比尔盖茨做 CEO 的时代，也经历过 Steve Ballmer 领导的年代，离开后也一直关心微软的一举一动，听说了很多 Satya 做的决定。我从 2015 年就公开表达我对萨提尔的敬佩，觉得这人真牛。

![](/cn/2023/03/2965-15fdbeb9.webp)

他的很多决定，在我看起来，非常务实、符合理性。

最让我震撼的事情就是对于 Linux 和开源软件的态度。

我还在微软的时候，跟 Linux 打了多少年，天天就在对比 Windows 和 Linux，对比总体拥有成本（TOC）等等，把 Linux 当作 Windows 最大的威胁。而萨提亚上任后直接就打出来了「Microsoft ❤️ Linux」标语。

![](/cn/2023/03/2965-eaf2e468.webp)

我看了以后一口鲜血吐出来，反应了好久，心想这脑洞开得也太大了，「还可以这样的！」，但细想又如此合理。

后来微软可以说是 Linux 运动里的最大的受益者。在微软云上面， 60% 的机器跑在 Linux 上，Windows 里面的 WSL 直接就可以运行 Linux 的程序。现微软几乎就是一家 Linux 公司。

后来微软也和开源社区和解了，不仅不再攻击开源软件，还把开源软件的大本营 Github.com 给买了。

![](/cn/2023/03/2965-5e9e8eda.webp)

还有一件事情，是我听还在微软的老同事说。微软员工在公司使用 iPhone总是有种奇奇怪怪的拧巴。Satya 在员工大会上说：「我们就把话说明了，微软员工当然可以用 iPhone。」，并且他在公司外演示 Outlook 的时候，用的也是 iPhone 手机。而此之前 Baller 可是当众把员工手里的 iPhone 抢过来放在地上假装用脚踩的。

萨提亚让微软变得没有那么大的 ego，大大方方的承认 Windows 不再是微软最重要的产品，云才是。作为在微软工作过很久的老员工，我知道这太难了。Windows 这款微软血液里面流淌的产品，从来没有人去想过可以撼动，这里面混杂了太多感情的因素，结果 Satya 像 ChatGPT 一样冷静的做了这个大决定。

对于威胁，是如猫炸毛一样的考虑「战或逃」是人的直觉反应，而冷静下来分析利弊，做出惊人但是符合逻辑的决定这一点，萨提亚真的做得很好。
