In the last few weeks, after moving my server to [IpowerWeb](http://home.wangjianshuo.com/archives/20040404_still_working_with_ipowerweb.htm), the Shanghai Map Viewer does not work as it well as before. Actually, the IPowerWeb only support Perl and PHP while the previous version [0.71](http://home.wangjianshuo.com/archives/20040206_shanghai_map_viewer_071_released.htm) was written in ASP + Access database.

In the last few days, I migrated the application to PHP version so the original links to this site is not broken. Now, only the most two baisc functions work.

1. Navigate using the thumb view.

2. Navigate via 8 direction arrows.

3. Display places names if it is encoded in URL, such as  [Jian Shuo Wang's Pudong Home](http://home.wangjianshuo.com/scripts/map/?x=3800&y=3200&cx=190&cy=370&text=Jian%20Shuo%20Wang's%20Pudong%20Home), or [Ramada Hotel (Pudong)](http://home.wangjianshuo.com/scripts/map/?x=4400&y=2200&cx=405&cy=155&text=Ramada%20Hotel%20Pudong).

4. You can add a point to the map now and embed the map into any web page.
